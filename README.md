# 得到大脑 Skill

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

把得到大脑装进你常用的 AI。之后只要说“记一下”“帮我找找”或“整理到知识库”，AI 就能帮你保存、查询和整理笔记。

适用于 WorkBuddy、Claude、Codex、OpenClaw 生态及其他支持安装 Skill 的 AI。

## 你可以直接这样用

### 随手保存一个想法

> 记一下：支付流程可以加一个进度提示，让用户等待时不焦虑。

AI 会保存文字并返回笔记标题和可打开的笔记链接。

### 保存网页或公众号文章

> 帮我保存这个链接：https://example.com/article

AI 会等待网页内容处理完成，再返回生成好的笔记，不会把空白笔记说成保存成功。

### 保存图片

> 把这张图存到我的得到大脑。

AI 会上传图片，等待识别和笔记生成完成，再把结果发给你。

### 找回以前的记录

> 帮我找找最近记过的客户反馈。

AI 会返回相关笔记的标题和链接。你也可以说“最近有哪些笔记”或直接给出笔记 ID 查看详情。

### 整理到知识库和文件夹

> 在“产品研究”知识库里找到“竞品”文件夹，把刚才那篇笔记放进去。

AI 会先读取你真实可用的知识库和目录，再完成归档，不会凭名称猜 ID。默认知识库、书籍、客户档案和团队知识库都能正确识别；团队成员可以阅读，拥有者或管理员可以加入笔记。

### 读取录音、会议和链接原文

> 把这条会议笔记的完整转写、附件和时间点列出来。

AI 会按需读取录音转写、网页原文、附件、时间线和快捷笔记，不会拿摘要冒充原文。

### 订阅抖音博主

> 把这个抖音博主订阅到“行业观察”知识库：https://www.douyin.com/user/example

AI 会确认目标知识库和写入权限后创建订阅，之后可以继续查询博主内容。

## 能做什么

| 场景 | 支持能力 |
|---|---|
| 记录 | 保存文字、长文、网页链接和本地图片 |
| 查找 | 最近笔记、语义搜索、笔记详情和可打开链接 |
| 深度阅读 | 链接原文、录音转写、附件、时间线、快捷笔记和从明确章节解析的会议待办 |
| 维护笔记 | 修改标题或正文、管理标签、删除和分享 |
| 整理知识 | 管理默认、书籍、客户档案和团队知识库 |
| 文件夹 | 浏览、创建、移动和删除目录，把笔记放进指定目录 |
| 内容订阅 | 订阅抖音博主，查看博主内容和直播总结 |
| 内容关联 | 创建父子笔记、用笔记链接串联相关内容 |

链接和图片通常需要一些处理时间。得到大脑会等到内容真正生成完成后再回复结果；如果处理失败，会说明原因和下一步，不会重复保存同一份内容。

## 安装

### 方式一：发一句话给 AI（推荐）

把下面这句话发给 WorkBuddy、Claude、Codex 或其他能够安装 Skill 的 AI：

> 请从 GitHub 仓库 https://github.com/iswalle/getnote-openclaw 安装得到大脑，自动完成所需依赖；安装后引导我授权，并保存一条测试笔记确认可以正常使用。

接下来按 AI 的提示在浏览器完成得到大脑授权即可。不要在聊天中粘贴 API Key、Cookie 或其他账号凭证。

### 方式二：从技能市场安装

在 ClawHub、SkillHub 或 AI 自带的技能市场中搜索“得到大脑”或 `getnote`，点击安装。安装后对 AI 说：

> 开始使用得到大脑，带我完成授权并保存一条测试笔记。

### 方式三：下载 Skill 安装包

如果你使用的 AI 支持“上传 Skill 压缩包”，可下载 [得到大脑 Skill 安装包](https://github.com/iswalle/getnote-openclaw/releases/latest/download/getnote-skill.zip) 后直接上传。

安装包包含运行所需的主 Skill、5 个领域 Skill 和官方 CLI 安装器；上传后把这句话发给 AI：

> 帮我安装这个得到大脑 Skill，自动安装官方 CLI、完成授权，并保存一条测试笔记确认可以正常使用。

如果下载链接暂时不可用，说明尚未发布新的安装包版本；请改用上面的“发一句话给 AI”或技能市场安装，不要下载 GitHub 源码压缩包替代安装包。

## 安装成功是什么样

完成首次授权后，让 AI 保存一条测试笔记。收到以下结果才算真正可用：

- 明确提示保存成功；
- 返回真实笔记标题；
- 返回可以打开的得到大脑笔记链接；
- 打开链接后能看到刚才保存的内容。

安装完成但还未授权时，AI 会打开浏览器让你确认账号。授权只需在得到大脑页面完成，不需要把密钥发给 AI。

## 日常使用不需要记命令

直接描述你想做的事即可，例如：

- “记一下今天的产品复盘。”
- “把这篇公众号文章存进客户档案。”
- “最近关于支付流程的笔记有哪些？”
- “打开这条笔记的录音原文。”
- “把这几条记录加上‘用户反馈’标签。”
- “在行业观察知识库里新建一个 AI Agent 文件夹。”
- “把这个抖音博主订阅到行业观察。”

涉及删除、覆盖正文、替换全部标签或公开分享时，AI 会先向你确认。

## 更新

不用判断该更新哪个组件，也不用自己运行安装命令。直接对 AI 说：

> 帮我把得到大脑更新到最新版，并检查能否正常保存和查询笔记。

AI 会自行检查、完成更新和验证；如果当前平台需要你点击确认，会明确告诉你下一步。

## 安装后会自动完成什么

Skill 会让 AI 安装官方 CLI，并按真实结果完成操作：保存链接或图片时，只有拿到笔记标题和可打开链接才会说保存成功；查询和整理时，只展示你账号实际可访问的笔记、知识库、文件夹和权限结果。

你不需要理解命令、参数或 API；只要直接说想做什么即可。

## 隐私和安全

- 默认返回只有当前账号能打开的私有笔记链接；
- 未经明确要求，不会自动公开分享笔记；
- 群聊和共享会话中不会主动展开私密笔记全文；
- 删除、覆盖、公开分享等高风险操作会先确认；
- 不会要求你在聊天中提供 API Key、Cookie 或 Authorization；
- 操作失败会保留错误原因和 `request_id`，方便排查。

## 常见问题

### 安装后为什么还不能读取笔记？

通常是还没完成账号授权。对 AI 说“帮我连接得到大脑”，然后在打开的浏览器页面确认即可。

### 为什么保存链接或图片需要等待？

网页需要抓取正文，图片需要上传和识别。AI 会等笔记真正生成完成后再返回链接，避免打开后还是空内容。

### 能使用团队知识库吗？

可以读取当前账号有权访问的团队知识库。团队拥有者或管理员可以把笔记加入其中；普通成员没有写权限时会收到明确提示。

### 遇到问题需要提供什么？

提供失败时间、AI 显示的错误原因和 `request_id` 即可。请勿发送 API Key、Cookie 或完整授权信息。
