# 得到大脑（原 Get 笔记）Skill

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

装上以后，在 OpenClaw（小龙虾）、WorkBuddy、Claude、Codex 等 AI 里，直接说话就能记笔记、存链接、找笔记、整理知识库。

## 安装

### 方式一：把一句话发给 AI（推荐）

> 请从 https://github.com/iswalle/getnote-openclaw 安装得到大脑 Skill，并引导我完成授权。

### 方式二：下载 Skill 安装包

打开 [发布页](https://github.com/iswalle/getnote-openclaw/releases/latest)，下载最新版 ZIP，拖进 AI 的聊天框，然后说：

> 请安装这个得到大脑 Skill，并引导我完成授权。

安装时 AI 会打开得到大脑授权页，你在浏览器点确认就行，不用复制 API Key。装好后 AI 会读一条你最近的笔记确认能用，不会自己乱建测试笔记。

Skill 需要官方 getnote 命令行工具，由 AI 平台按它的安装确认流程装好；Skill 本身不会执行下载脚本或自行覆盖文件。

所有得到大脑用户授权后都可以调用，会员享有更高额度。想看当前额度，让 AI 查一下就行。

## 能做什么

| 你说 | AI 做什么 |
| --- | --- |
| 「记一下：支付流程加个进度条」 | 存成文字笔记，可以带标签 |
| 「存到笔记 https://…」 | 抓取网页正文并生成摘要，支持公众号、小红书、B站、抖音、小宇宙等 |
| 发一张图片 | 识别图里的文字并保存 |
| 「上次讨论用户分层是怎么说的？」 | 按意思搜索你的笔记 |
| 「找昨天录音台的会议笔记，读讲到定价的那段」 | 按设备和时间找笔记，长笔记先看目录再按段读 |
| 「找博尔赫斯的书籍笔记」 | 按书名、作者、课程找划线和评论 |
| 「在『产品研究』里建个『竞品』文件夹，把这篇放进去」 | 整理知识库和文件夹 |
| 「把这个抖音博主订阅到『行业观察』」 | 订阅博主、得到直播，自动收进知识库 |
| 「把这条笔记分享出去」 | 生成公开链接 |

几点说明：

- 能新建文字、链接、图片笔记；录音、会议等笔记只能读，包括转写原文、时间线和会议待办
- 笔记正文里写 `https://biji.com/note/<笔记ID>`，就能链接到另一条笔记，适合用来串联每天的工作日志
- 搜索结果只是最相关的几条，没搜到不代表没有，AI 会换个方式再找

## 更新

对 AI 说：「帮我把得到大脑更新到最新版，并检查能不能正常读取和保存笔记。」AI 会升级命令行工具、同步 Skill，再检查一遍。

## 安全

- 笔记链接默认只有你自己的账号能打开
- 在群聊里不会主动展开你的私密笔记
- 删除、覆盖正文、替换全部标签、公开分享之前，都会先问你
- 不会让你在聊天里发 API Key、Cookie 这类登录信息
