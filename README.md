# 得到大脑 Skill

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

把得到大脑装进你常用的 AI。安装后，直接说“记一下”“帮我找找”或“整理到知识库”，AI 就能替你保存、查询和整理笔记。

适用于 WorkBuddy、Claude、Codex、OpenClaw 生态及其他支持安装 Skill 的 AI。

## 能帮你做什么

- 保存文字、长文、网页链接和图片，处理完成后返回可打开的笔记链接；
- 查看最近笔记，按自然语言搜索以前记录的内容；
- 读取笔记详情、网页原文、录音转写、附件、时间线、快捷笔记和会议待办；
- 修改或删除笔记，管理标签，生成公开分享链接；
- 管理默认知识库、书籍、客户档案和团队知识库；
- 创建和整理知识库文件夹，把笔记放进指定位置；
- 订阅抖音博主，查看博主内容和直播总结。

你不需要记任何命令，像平时聊天一样说明想做什么即可。

## 安装

只保留两种安装方式，任选一种即可。

### 方式一：把一句话发给 AI（推荐）

把下面这句话发给 WorkBuddy、Claude、Codex 或其他能安装 Skill 的 AI：

> 请安装 GitHub 仓库 https://github.com/iswalle/getnote-openclaw 中的得到大脑 Skill。请读取其中的 SKILL.md，自动安装官方 CLI，引导我在浏览器完成授权，并检查是否能正常读取笔记。

AI 会完成安装和检查。需要登录时，只在打开的得到大脑网页中确认，不要在聊天里发送 API Key、Cookie 或其他账号凭证。

### 方式二：下载 Skill 安装包

下载 [得到大脑 Skill 安装包](https://github.com/iswalle/getnote-openclaw/releases/download/v2.0.0/getnote-skill.zip)，直接拖进 AI 的聊天框，然后说：

> 请解压并安装这个得到大脑 Skill，按照 SKILL.md 自动安装官方 CLI，引导我完成授权，并检查是否能正常读取笔记。

安装包已经包含主 Skill、五个领域说明和自动安装脚本，不需要再下载 GitHub 源码。首次使用需要 Node.js 20 或更高版本和可访问 npm 的网络；Skill 会自动安装 CLI，不会替系统安装 Node.js。

## 安装成功是什么样

AI 完成安装后会依次确认：

1. 得到大脑 CLI 可以运行；
2. 已在浏览器完成账号授权；
3. 可以读取当前账号的笔记；
4. 当前 AI 已经加载得到大脑的保存、搜索、知识库和标签能力。

默认先用“读取最近一条笔记”验收，不会擅自创建测试内容。你明确同意后，AI 才会保存测试笔记。

## 可以直接这样说

### 保存内容

> 记一下：支付流程可以加一个进度提示，让用户等待时不焦虑。

> 帮我保存这个链接：https://example.com/article

> 把这张图存到我的得到大脑。

链接和图片需要抓取或识别。AI 会等内容真正生成完成，再返回标题和笔记链接，不会把空白笔记说成保存成功。

### 查找笔记

> 最近保存了哪些笔记？

> 帮我找找以前记过的客户反馈。

> 打开这条笔记的录音原文。

AI 会返回真实标题、摘要和笔记链接。没有找到时会如实说明，不会编造结果。

### 整理知识库

> 在“产品研究”知识库里新建“竞品”文件夹，把刚才那篇笔记放进去。

> 把这个抖音博主订阅到“行业观察”知识库。

AI 会先读取你真实可用的知识库、文件夹和权限，不会根据名称猜 ID。团队成员可以读取有权限的团队知识库；写入和维护仍以账号实际权限为准。

### 维护笔记

> 给这条笔记加上“用户反馈”标签。

> 把这条笔记分享给同事。

删除、覆盖正文、替换全部标签或公开分享前，AI 会先让你确认。

## 更新

直接对 AI 说：

> 帮我把得到大脑更新到最新版，并检查是否能正常读取和保存笔记。

AI 会更新 Skill 和官方 CLI，并重新检查连接。重复安装或更新不会清除已经保存的授权凭证。

## 隐私和安全

- 默认返回只有当前账号能打开的私有笔记链接；
- 未经明确要求，不会自动公开分享笔记；
- 群聊和共享会话中不会主动展开私密笔记全文；
- 删除、覆盖和公开分享等高风险操作会先确认；
- 不会要求你在聊天中提供 API Key、Cookie 或 Authorization；
- 操作失败会说明真实原因和下一步，并保留 `request_id` 方便排查。

## 常见问题

### 安装后为什么还不能读取笔记？

通常是还没完成账号授权。对 AI 说“帮我连接得到大脑”，然后在打开的浏览器页面确认即可。

### 为什么保存链接或图片需要等待？

网页需要抓取正文，图片需要上传和识别。AI 会等笔记真正生成完成后再返回链接，避免打开后还是空内容。

### 能使用团队知识库吗？

可以读取当前账号有权访问的团队知识库。拥有者或管理员可以把笔记加入其中；普通成员没有写权限时会收到明确提示。

### 遇到问题需要提供什么？

提供失败时间、AI 显示的错误原因和 `request_id` 即可。请勿发送 API Key、Cookie 或完整授权信息。

## 版本更新

### v2.0.0

- 改为“Skill 理解用户意图，官方 CLI 稳定执行”，减少 AI 猜参数和直接拼 API 导致的失败；
- 与 CLI 1.5.1 对齐，支持保存、查询、深层笔记内容、知识库文件夹、团队知识库和抖音博主订阅；
- 链接和图片保存会等待最终生成结果，再返回真实笔记标题、字符串 ID 和链接；
- 安装收敛为“发一句话给 AI”和“上传 Skill 安装包”两种；
- 支持自动安装或升级官方 CLI，重复安装不会清除授权凭证；
- 五个领域说明与 CLI 内置 Skill 使用同一套命令和结果约定。
